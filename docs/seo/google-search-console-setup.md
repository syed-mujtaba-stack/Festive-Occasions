# Google Search Console — Sitemap Submission Guide

**Audience:** Festive Occasions (client) — step-by-step, non-technical.
**Status:** Sitemap already live and verified; this guide is the only remaining
action, and it must be done from the client's own Google account (we cannot
submit on their behalf).

---

## Why this matters

GSC is how you tell Google "this site exists, here are my main pages" and how
you track which keywords actually bring visitors. Submitting the XML sitemap is
the single most useful thing for getting all ~29 pages + images indexed.

## Prerequisite

- A Google account (any Gmail works).
- Access to the live production domain `festiveoccasions.ae` (DNS or whoever
  manages the hosting for it). The sitemap we ship points at
  `https://festiveoccasions.ae/sitemap.xml` — verify the **production** domain,
  not the development URL.

## Steps

### 1. Add your site

1. Go to <https://search.google.com/search-console> → sign in with Google.
2. Click **Add property** → choose **Domain**.
3. Enter: `festiveoccasions.ae` (no `https://`, no `www`).
4. Continue → Google gives you a DNS TXT record to add.

### 2. Verify you own the domain

- Add the TXT record at whoever manages the domain's DNS
  (registrar or hosting panel: `_dns.google` → add TXT `google-site-verification=...`).
- Click **Verify** in GSC. Propagation can take a few minutes to a few hours.

> If the client would rather skip DNS, use the **URL prefix** method instead
> (`https://festiveoccasions.ae`), then verify via the HTML file or meta tag.
> DNS is preferred because it verifies the whole domain.

### 3. Submit the sitemap

1. In GSC, go to **Sitemaps** (left menu).
2. Enter: `sitemap.xml`
3. Click **Submit**.
4. Within minutes/hours you should see "Success" with pages discovered.

The sitemap is generated by the site itself — no need to re-upload it when
content changes; Google re-reads it and it updates automatically.

### 4. (Optional) Request indexing of key pages

- **URL Inspection** (top search bar in GSC) → paste a URL →
  **Request Indexing**. Do this for the most important pages:
  - `https://festiveoccasions.ae/`
  - `https://festiveoccasions.ae/christmas-decoration-dubai`
  - `https://festiveoccasions.ae/packages`
  - `https://festiveoccasions.ae/blog`

### 5. What to watch after a few days

- **Performance** report → see which keywords/pages get impressions.
- **Indexing** report → confirm all main pages are "Indexed".
- Report any "not indexed" surprises back to the development team.
