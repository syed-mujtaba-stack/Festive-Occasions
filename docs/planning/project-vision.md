# Project Vision — Festive Occasions Website Revamp

**Domain:** festiveoccasions.ae
**Market:** Premium Christmas & Festive Decoration Studio — Dubai / UAE
**Budget context:** ~PKR 200,000 (premium expectation)

## Core Positioning

- **Primary:** Premium Christmas Decoration in Dubai
- **Secondary:** Bespoke Festive & Event Decoration

## The 5 feelings a visitor must get on arrival

1. This is a professional company.
2. They do premium decoration.
3. Their actual projects are impressive.
4. They can transform my property/event.
5. I want to contact them via WhatsApp / call / quote.

## Visual Direction

Luxury editorial + Christmas + UAE event styling.
NOT a cheap Christmas template with red/green graphics.

## What the website is NOT

- Not a generic decoration-company template
- Not a keyword-stuffed SEO page
- Not a showcase of fake/stock claims
- Not 50 thin doorway pages

## Winning combination

```
FESTIVE OCCASIONS
  ├── Premium UI (GSAP/Motion, Portfolio, Luxury Feels)
  └── SEO (Service Architecture, Local SEO, Dubai Intent)
        └── LEADS (WhatsApp / Call / Quote)
```

The website must simultaneously:
LOOK PREMIUM → EXPLAIN SERVICE → SHOW PROOF → RANK → CONVERT

## Acceptance bar

> "Agar main 200k pay kar raha hota, kya mujhe ye premium lagti?"

Every section must pass this test. If any section feels like a template → redesign it.
